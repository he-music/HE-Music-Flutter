# Material 与 Cupertino 界面风格验收

## 运行

```sh
flutter run --profile -d <device-id> --dart-define-from-file=.env
```

在“设置 → 外观 → 界面风格”选择 Material 或 Cupertino。旧液态玻璃构建开关及质量设置已移除。性能比较应使用相同真机、主题、皮肤、歌曲与刷新率；分别记录 UI/raster 帧耗时，不把组件测试通过解释为真机性能通过。

## 检查项目

| 场景 | 预期 |
| --- | --- |
| 两种风格，浅色/深色及壁纸皮肤 | 导航、搜索框、开关和弹窗体现所选设计语言，皮肤和主题色仍生效 |
| 经典皮肤下对照两种风格 | Material 保留卡片与下划线标签；Cupertino 使用中性分组背景、分组行、17pt 正文、系统图标和回弹滚动 |
| Apple 蓝主题色 | 两种风格均可选择，浅深色分别生效，重启及切换风格后保留；壁纸皮肤继续遵守自身配色权限 |
| Cupertino 列表的长值与大字号 | 当前值可换行，完整说明可读；按钮、开关及排序确认仍可操作，桌面 Enter/Space 可激活列表行 |
| 更换风格并重启 | 选择被保存；未知存储值回退 Material |
| 保持二级页面并切换风格 | 路由、播放队列、浏览位置和已有输入保留 |
| 首次安装与手动选择 | iOS/macOS 未手动选择时采用 Cupertino，其他平台采用 Material；手动选择并重启后优先使用保存值，不修改真实平台 |
| 资料库与原入口 | 本地音乐、下载、播放历史、收藏、自建及收藏歌单可达；原“我的”入口和 `/library` 本地音乐链接仍可用，离线可进入资料库，未登录时云端入口登录后回到资料库 |
| 从各标签 push 普通浏览详情 | Cupertino 保留标签栏和原选中标签；Material 详情隐藏标签栏；整条导航链仅有一个播放条，返回后恢复原标签与滚动位置 |
| 详情切换风格再返回 | root、外层内容和分支 Navigator 实例保持稳定，搜索输入、焦点、滚动与播放保留；标签切换 go 到对应分支，无重复详情栈 |
| 播放器、视频、登录、设置与编辑 | root 全屏覆盖共享底栏和播放条，返回仍回到原内容页；弹窗优先关闭并正常返回结果 |
| 全屏播放器中的详情与再次打开播放器 | 歌手／专辑／歌曲／评论／歌单等请求转入固定 root 浏览别名；返回先回播放器，详情再次开播放器后只保留一个播放器，返回详情及来源页的状态仍在，Cupertino 标签栏显示来源分支 |
| iOS 设置分区边缘返回 | 慢拖取消保留分区；拖过半屏完成回到设置；前后透明页面相邻移动，无叠画，连续返回及点击可用；系统减少动画时无位移动画，Android 返回策略不变 |
| 发现/资料库/我的切换、宽屏缩放 | 分支浏览状态保留，底栏固定，迷你播放器与内容不互相遮挡 |
| Material 底部控制区 | 全宽 M3 导航保留选中指示，播放条贴合其上，仅顶部圆角；无歌曲时播放条隐藏，导航仍可用 |
| Cupertino 底栏与安全区 | 导航背景贴合屏幕左右及底部边缘，迷你播放器独立浮动；键盘开合后位置稳定 |
| 独立播放条与横向安全区 | Material 底色铺满底部安全区，内容避开左右缺口；Cupertino 保留浮动间距。键盘出现后两者高度与位置保持稳定 |
| Cupertino 各内容页面与底色开关 | 歌曲、搜索结果、歌单／专辑／歌手／视频、排行榜、评论、下载、乐谱等共享表面不绘制装饰外框或阴影；关闭底色后仅保留必要分隔和选中反馈 |
| Cupertino 设置分组、功能入口与普通 Card | 统一受“显示内容背景”控制，开关前后分组、点击与局部状态正常；搜索输入、迷你播放器、底栏及弹窗外壳保持独立底色 |
| Cupertino 弹层内部选项分组 | 风格、主题色、字体、缓存上限、播放／下载音质等选项遵循内容背景开关；外壳始终不透明，分隔线、勾选和点击反馈保留；弹层已打开时切换背景不改变滚动、焦点或选中项 |
| Cupertino 空态、错误态和嵌套内容 | “我的”歌单空态／重试卡、在线快捷入口及元信息底色与普通内容使用同一开关；必要的错误文字、重试按钮和操作保持可用 |
| Cupertino 透明页面的普通标题栏 | 标题栏及状态栏区域透出壁纸，无白色横条或背景模糊；实色页面仍有正常底色，浅深色状态栏图标清晰 |
| 切换经典／城市声场／星轨旋律及内容底色 | 局部组件状态与浏览位置保留，内容字号放大至两倍仍可操作；皮肤配色及选中边框仍生效 |
| Cupertino 壁纸与静态遮罩 | 文字所在背景适度淡化；已有强遮罩不重复加重，动画继续遵循原有设置，不增加背景模糊 |
| 播放、暂停、左右滑动切歌、队列选歌 | 播放行为与返回值正常，两种风格共用播放状态 |
| 搜索输入、提交和清空 | 回调正确，清空保留焦点；桌面 Tab 焦点提示可见 |
| Material 搜索平台筛选 | “小黄／小鹅”等短标签显示为紧凑胶囊且文字垂直居中；外层点击区域至少 48dp，胶囊之外的命中区域可点击，双倍字号不裁切或溢出 |
| Cupertino + 经典皮肤 + Apple 蓝的浅深色搜索框 | 首页搜索入口、通用搜索框和在线搜索框底色一致；半透明输入底色先与控制表面混合，浅色不变深灰，个人资料编辑框保持正确填色 |
| 设置分区标题与当前值 | 导航栏仅显示一次分区标题，正文保留组标题；主题、主题色和语言的当前值各显示一次 |
| 打开队列、排序、速度、音量、睡眠定时面板 | 长内容直接滚动，确认/取消结果正确，拖动关闭后页面仍可操作 |
| MiniPlayer 与详情页的队列入口 | 同一明暗模式和风格下表面一致，Material / Cupertino 顶部圆角分别为 24 / 16；选歌、删除、重排及历史队列正常，进度变化不重建面板 |
| 播放器弹层中的风格控件 | 选项、按钮、开关、倍速／音量／歌词亮度滑块跟随风格；Cupertino 队列及样式分类使用分段选择，放大字号仍可访问 |
| 滑块交互 | Cupertino 从拇指开始拖动；键盘方向键、Home/End、RTL、读屏增减正确提交，禁用时不提交 |
| 自定义睡眠时长 | Material 下拉、Cupertino 滚轮，零时长禁止确认；弹层内切换风格后当前时长保留 |
| 弹层内切换风格或明暗模式 | 当前路由、输入焦点和编辑值保留；嵌套面板跟随明暗模式，返回结果与系统栏保护正常释放 |
| 播放器打开弹层再关闭 | 不把普通弹层视为离开播放器，屏幕常亮与频谱状态保持正确 |
| 小屏、横屏、两倍字号和键盘 | 操作可访问，无溢出或双重键盘避让；底栏不随键盘跳动 |
| 桌面菜单、嵌套 Navigator、窗口边角 | 菜单定位正确，长菜单末项可点击，关闭不退出详情页 |
| 皮肤动画开关与系统减少动画分别切换 | 皮肤开关仅影响背景动画，页面组件按系统设置减少动画 |
| TalkBack/VoiceOver 与键盘操作 | 标签、禁用态、破坏性操作、焦点与关闭入口可用 |

性能检查覆盖连续滚动首页 30 秒、快速切歌 10 次、队列开关 10 次及动态背景播放。60 Hz 的帧预算约 16.7ms，120 Hz 约 8.3ms。记录 `平台 / 设备 / 风格 / 主题与皮肤 / 操作 / 帧耗时 / 截图或录屏`。本次自动化改造不代替这项人工验收。

## 自动化与预览

执行 `make analyze`、`make test` 检查共享组件、路由生命周期和交互回归。`make skin-previews` 更新内置皮肤首页基线，并导出 Cupertino 首页与设置预览；更改基线后同步资源 provenance 与 SHA-256。

执行 `make player-interface-previews` 将两种风格、浅深色的更多操作、倍速、睡眠定时、样式选择和队列共 20 张真实组件截图导出至 `/tmp/he-player-interface-previews/`。该入口使用固定测试歌曲与图片，不读取用户资料。
