# 章节排序

共享歌曲排序菜单提供“章节”（英文为 `Chapter`），用于广播剧、有声书等包含明确编号的标题。默认顺序和原有标题、歌手、专辑排序保持原有规则。

## 识别范围

- 中文标记：`第X季 / 部`、`第X集 / 话 / 章 / 节 / 回`，兼容常用繁体标记。
- 编号：阿拉伯数字、全角数字、带十百千单位的中文数字，以及 `二〇二四` 形式的逐位数字；罗马数字兼容 `IV`、`Ⅳ` 等形式。
- 英文标记：`S02E12`、`S02 E12`、`EP12`、`Episode 12`。
- 分段：编号之后的“上 / 中 / 下”，例如 `第十集（上）`。
- 特殊内容：前传、序章、序幕、大结局、最终集、最后一集、完结篇、番外、特别篇、独立单词 `SP / OVA` 等。
- 最终季：最终季、最后一季、末季、完结季。

仅有 `001`、年份或普通歌词中的中文数字不构成章节编号。未知命名保持原始顺序，不尝试猜测。

## 排列规则

1. 使用首个明确标记之前的标题前缀分组，只清理前缀两端的常见分隔符和括号。不同前缀不做模糊合并。
2. 作品前缀使用独立的 ICU 中文数字自然排序比较器，因此 `作品2` 位于 `作品10` 之前。
3. 同一作品按编号季、最终季、季号未知的内容排列。同一作品只有一个明确编号季，且没有最终季标记时，省略季号的内容归入该季；其他情况不猜季号。
4. 同一季升序为：季标题、前传或序章、编号正文、无编号结局、番外或特别篇。前传是篇章类型，不强制当作第 0 季。
5. 正文按章节号、上中下分段排列。带编号的结局优先使用编号；带编号的番外仍属于番外。
6. 未识别标题在升序和降序下均放在末尾；相同键和未识别标题始终保留各自的原始顺序。
7. 每次排序只解析每个标题一次，比较时复用已经生成的键。

排序偏好沿用共享持久化设置；恢复偏好只更新显示，用户主动确认排序时沿用现有播放队列同步入口。分页列表仍需全部加载后才能排序。

本地曲库仍使用数据库提供的原有排序字段。章节比较器与 SQLite 文本 collation 独立，不改变已有索引规则。
